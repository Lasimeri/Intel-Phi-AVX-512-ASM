
## Stage 3 (2026-10-13)

| file | role |
| --- | --- |
| [`decode.S`](decode.md) | the x86-64 decoder: `x86_decode(bytes, n, out, address)`, every field checked against iced-x86 on 2.34 million instructions |
| [`x86dec.inc`](x86dec.md) | the decoded block, the length table's and the entries' layouts |
| [`x86tab.inc`, `x86tab.h`](x86tab.md) | the tables, generated by `tools/gen-x86-tables.c` from `tools/x86-opcodes.txt` |
| [`fnscan.S`](fnscan.md), `fnscan.inc` | a function indexed over the decoder: kinds, labels, counts; checked by `tools/fnscan-check.c` against the dump (830 functions, every count equal) |
| [`mvex.S`](mvex.md) | the emitter: the MVEX prefix and operand forms, mask ops, scratch saves, temporaries, constants, the vector helpers (a port of rewrite.rs's `Em`) |
| [`xlate.S`](xlate.md), `xlate.inc` | the recipes by mnemonic: one-to-one forms, lane masks for 128/256-bit forms, zeroing, memory operands staged, extracts, shuffles, scalar forms |
| [`blob.S`](blob.md) | a function's blob: copies, re-based rip-relative operands, re-laid branches, exits through the transfer slot, constants, the rip map |
| [`xlfn.S`](xlfn.md) | a seed translated at its first fault, loaded on every card, entered through the map (`PHI512_HANDBLOBS=1` keeps the hand blobs) |
